# Taskly の構想と過去の提案

旧仕様書にあった構想の記録です。検討状況と実施時期は GitHub の Issue・PR で管理します。利用できる機能は[現行仕様](Specification.md)を参照してください。

## ネイティブアプリの構想

- iOS・iPadOS と macOS、Android、Windows 向けのネイティブアプリ。
- OS の通知、課題件数のバッジなど、各プラットフォームの機能を使った課題管理。
- 旧案で挙げた技術候補は Apple 向けの Swift、Android 向けの Kotlin、Windows 向けの WinUI 3。

## 旧案にあった機能

- 管理画面から日付範囲を指定して休日・営業日を設定するカレンダー管理と、システム全体のログ閲覧。
- 利用者がアカウントの操作履歴を確認する画面。
- 日直の未履行を手動で記録し、次回の割り当てへ反映する運用。
