# PR のレビューとセルフマージ

`main` に向けた PR のマージには、リポジトリの書き込み権限を持つメンバーからの承認が 1 件必要です。書き込み権限を持つメンバーが自分で作成した PR は、承認の代わりに本人が `self-merge <full-commit-sha>` とコメントできます。対象コミットは PR の先頭の 40 桁の SHA を指定します。必須 CI とコミット署名はどちらの場合も必要です。

GitHub の署名付き通知を共通の実行先が受け取り、PR が開いていてレビュー可能な状態であること、投稿者と PR 作成者のアカウント ID が一致すること、投稿者に現在も書き込み権限があることを確認します。App は対象リポジトリに限定されたトークンで指定 SHA のマージを依頼します。コミットが変わった場合は新しい内容を確認してからコメントし直します。

承認1件はレビュー専用ルールセットで要求し、PR 経由のレビュー例外は専用 App にだけ付与します。各リポジトリの CI や署名は既存のブランチ保護で強制します。共通実行先の設定とログは [Taskly PR automation](https://github.com/asari194617/taskly-pr-automation) で管理します。
