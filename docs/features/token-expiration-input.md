# トークン設定の有効期限入力

iCal トークン、API キー、MCP トークンの設定画面は `apps/web/src/lib/token-expiry.ts` を共通で使用する。
`DateTimePicker` の値はブラウザーのローカル日時 `YYYY-MM-DDTHH:mm[:ss]` として解釈し、GraphQL には UTC の RFC3339 を送る。

- 新規作成時の空欄は期限なしとして引数を省略する。
- 更新時の空欄は空文字列を送る。サーバーはこれを期限解除として扱う。
- 存在しない日付・時刻や夏時間移行で欠ける時刻は拒否し、共通の入力エラーメッセージを表示する。
- 既存期限を開いて変更せずに保存した場合は、取得時の RFC3339 値をそのまま送る。秒未満や夏時間の重複時刻も保たれる。

変更時は `apps/web/src/lib/token-expiry.vitest.ts` のタイムゾーン・日付境界・空欄・不正値・再編集のテストを更新する。
