# 日直の新しいバッチ処理の方式
- 日直の通知は毎日8:30に行う。
- 通知はEmailとWebPushで行う。
- サイクルとグループからなる日直の構成自体は変更しない。
- サイクルの中でグループをidの昇順でソートし、mod(剰余)演算で担当を決定する。
  - 例: グループが3つの場合、日直は1日目は1番目、2日目は2番目、3日目は3番目、4日目は1番目...n日目は(n%3)番目となる。
- n日目の値は、DBのconfigsテーブルに保存し、バッチ処理のたびにインクリメントする。
  - configsテーブルはkey-value形式の設定保存用テーブルであり、他の設定も保存できるようにする。
  - keyは`day_shift_current_index`、valueは文字列形式の整数とする。
  - テーブルのマイグレーションはapps/server/migrationsに追加する。
- 祝日や休日はインクリメントを行わない。
  - 平日でも行わない日の判定には、Googleカレンダーにある年間行事予定を利用する。
  - URL: https://calendar.google.com/calendar/ical/383f9f7a757bde1769f735fb29e49bb8f2511aa4b856049478aa5ebebf38cef0%40group.calendar.google.com/private-19b492f962ce44a9bbc41af48ad0980a/basic.ics
  - 当該行事により日直業務を行わない場合、`DESCRIPTION`フィールドに`DAY_SHIFT_OFF`という文字列が含まれている。バッチ処理の際には当該日が含まれるイベントを全て確認し、`DAY_SHIFT_OFF`が含まれている場合はインクリメントを行わない。
  - 学校カレンダーの予定は JST の対象日 00:00〜翌日 00:00 との重なりで判定し、通知に表示する行事一覧にも同じ判定を使う。タイムゾーンなしの時刻は JST として扱う。`DTSTART` は含み、`DTEND` は含まないため、翌日 00:00 終了の予定と終日予定の排他的終了日は翌日の対象外となる。`DURATION` は開始時刻からの経過時間として扱う。
  - その他、土曜日・日曜日・祝日は休日とみなす。
    - 祝日は`one.webcal.jp/JapanHolidays/`から提供されるiCalデータを利用する。
    - URL: https://one.webcal.jp/JapanHolidays/
    - 祝日判定は毎日バッチ処理の際に行う。
  - 休日判定のためにiCalデータを取得する際、ネットワークエラー等で取得に失敗した場合は、当該日のインクリメントを実行する。この際、DiscordとSentryにエラーログを送信する。
- 管理者画面では、以下の機能を提供する。
  - 日直サイクルの一覧およびサイクルのCRUD
  - 各サイクルに紐づいたグループ一覧およびグループのCRUD
  - 日直の現在のインデックス値の閲覧および手動更新
- バッチ処理はAirflowのDAGとして実装し、`infra/airflow/dags/`に配置する。
- インクリメントバッチ処理の時間は変更なし(3:00)
