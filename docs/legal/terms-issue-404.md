# 利用規約改定案（Issue #404）

状態: **公開前の案**。この文書の追加だけでは、公開中の[利用規約](https://policies.taskly.iy0306.com/terms/)は変更されない。法務レビュー、提供実態の確認、既存利用者への事前通知を済ませてから公開する。

## 2026-09-22 時点の確認

- `origin/main` のアプリ、サーバー、DB マイグレーション、仕様を検索した範囲では、利用料の請求、決済、支払遅延を扱う経路は確認できなかった。iCal の「購読」はカレンダー連携であり、課金ではない。
- 運営者への確認で、アプリ外も含めて有料契約、利用者への請求・決済はないと分かった。公開中の第4条は有料部分の料金と年14.6%の遅延損害金を規定し、第7条1項3号も料金債務の不履行を登録抹消事由にしており、現状と一致しない。
- 公開中の第9条3項は軽過失時の賠償上限を「損害が発生した月に受領した利用料」とする。無料利用者には 0 円上限と読め、第9条2項の消費者契約に関する例外とも関係が分かりにくい。
- 第3条3項、第6条2項、第7条2項、第9条4項にも一律に責任を否定する表現があるため、第9条だけでなく合わせて改める。
- 現在の同意記録は `users.is_agreed_policies` の真偽値だけで、同意した版と日時を残していない。この改善は [Issue #402](https://github.com/asari194617/taskly/issues/402) で扱う。

## 差し替える条文案

以下は現在公開中の日本語本文の該当箇所だけを差し替える案。条番号を維持し、他の条文はこの改定では変更しない。将来、有料提供を始める場合は、その開始前に第4条と第7条を改めて検討する。

### 第3条3項

> ユーザーIDまたはパスワードが第三者に使用されたことによりユーザーに損害が生じた場合、当サービスの責めに帰すべき事由による損害については、法令に従い責任を負います。

### 第4条（利用料金）

> 本サービスは、現在、ユーザーから利用料金を受領せずに提供しています。有料の機能またはサービスを提供する場合には、その内容、料金、支払方法その他の条件を事前に明示し、利用を希望するユーザーの同意を得た上で提供します。

現行第4条2項の年14.6%の遅延損害金は削除する。

### 第6条2項

> 本サービスの停止または中断によりユーザーに損害が生じた場合、当サービスの責めに帰すべき事由による損害については、法令に従い責任を負います。

### 第7条1項

現行3号「料金等の支払債務の不履行があった場合」を削除し、後続の号番号を繰り上げる。

### 第7条2項

> 本条に基づく利用制限または登録抹消によりユーザーに損害が生じた場合、当サービスの責めに帰すべき事由による損害については、法令に従い責任を負います。

### 第9条（保証の否認および損害賠償）

第9条冒頭のセキュリティポリシーへの案内は維持する。本文は次の4項に差し替える。

> 1. 当サービスは、本サービスについて、常に中断なく利用できること、特定の目的に適合すること、または誤りがないことを保証するものではありません。ただし、法令に基づく当サービスの責任を免れるものではありません。
> 2. 当サービスの債務不履行または本サービスの提供に際して行われた不法行為によりユーザーに損害が生じた場合、当サービスは、故意、重大な過失または軽過失のいずれによる場合も、法令に従い損害賠償責任を負います。
> 3. 前項の損害賠償について、利用料金の額による上限は設けません。損害の範囲その他の事項は、法令に従います。
> 4. ユーザーと他のユーザーまたは第三者との間の取引、連絡または紛争について、当サービスの責めに帰すべき事由によりユーザーに損害が生じた場合、当サービスは法令に従い責任を負います。

この案では、無料利用者の賠償上限が 0 円になる問題を避けるため、有料利用者にも同じく料金連動の上限を設けない。軽過失時の特別損害についても契約による一律の除外を設けない。

## 責任の読み方

| 場面 | 改定案での扱い |
| --- | --- |
| 無料利用者に損害が発生 | 利用料 0 円を理由に賠償を 0 円にしない。帰責事由、因果関係、損害の範囲を法令に従って判断する。 |
| 当サービスの軽過失 | 一律免責や料金額の上限を設けず、法令に従って判断する。 |
| 当サービスの故意・重大な過失 | 一律免責や料金額の上限を設けず、法令に従って判断する。 |
| 当サービスに帰責事由のない第三者間の紛争 | 当サービス自身の責任の有無を法令に従って判断する。 |

## 公開・適用手順

1. 運営者に確認した、アプリ外を含め有料契約、請求・決済がないという現状を、公開前にも再確認する。開始予定の有料提供があれば、その内容を踏まえて条文を修正する。
2. 法務担当者が、差し替え箇所と残る全文について、消費者契約法第8条・第10条、民法その他の適用法令との整合性をレビューする。特に上記の責任区分と第11条の変更手続を確認し、承認者と日付を記録する。
3. 公開中の旧版全文を、取得日時と公開 URL とともに変更不能な版として保管する。新版本文にも版番号と施行日を明記し、旧版への到達方法を用意する。[Issue #402](https://github.com/asari194617/taskly/issues/402) の同意版記録・既存利用者への適用方針と整合させる。
4. 施行日を将来日に設定し、変更点、新旧全文へのリンク、施行日、問い合わせ先を、アプリ内表示と登録済み連絡先への通知など到達を確認できる方法で事前に知らせる。通知日時と対象を記録する。再同意が必要と判断された利用者には、施行前に同意導線を用意する。
5. 通知と版保管を確認してから公開 Notion ページを更新する。施行日までは旧版の適用関係を確認できるようにし、施行後に同意画面・フッターから最新版と旧版へ到達できることを確認する。

公開中のページを先に書き換えると、既存利用者に対する事前通知と旧版の再現ができなくなるため、上記の順序を守る。
