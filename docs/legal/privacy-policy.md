# プライバシーポリシー

2026年9月23日改訂

Taskly（以下「本サービス」）は、個人が運営する課題管理サービスです。本ポリシーは、本サービスにおける個人情報の取扱いを説明します。

## 1. 運営者と連絡先

運営者の氏名・住所は、下記の窓口へお問い合わせいただければ遅滞なく回答します。個人情報の取扱いに関するお問い合わせ、苦情、開示等のご請求も同じ窓口で受け付けます。

連絡先：[lyrical_beagles.9r@icloud.com](mailto:lyrical_beagles.9r@icloud.com)

## 2. 取得する情報

1. アカウント・認証：メールアドレス、表示名、言語・通知設定、ポリシーへの同意状況、パスワードのハッシュ、ログインコード、パスキー公開鍵、二要素認証情報、セッション情報。
2. サービスの利用：課題のタイトル・説明・期限・作成者・完了状況、日直の担当、通報内容、利用者が設定した API・MCP・iCal 連携情報。
3. 通知：通知先メールアドレス、Web Push の購読先と鍵、通知内容・配信状況。
4. 外部連携：Teams 等から受け取るメールアドレス・課題内容・メッセージ ID、受信メール連携に届く送受信元・件名・本文・添付情報。
5. 運用・セキュリティ：アクセス元 IP アドレス、操作・認証・障害に関するログ。

課題の説明や通報コメントなどの自由入力欄に、利用者が個人情報を記入する場合があります。必要以上の情報を入力しないでください。登録時に生年月日、住所、銀行口座番号、クレジットカード番号、運転免許証番号の入力は求めていません。広告・決済提携先から取引記録を収集する機能や、有料サービスの請求機能は提供していません。

## 3. 利用目的

取得した情報は、アカウントの作成・認証、課題・日直等の機能の提供、選択した通知・外部連携、お問い合わせ・開示等への対応、不正利用防止、モデレーション、障害対応・セキュリティ確保、バックアップ・復旧のために利用します。利用目的を変更するときは、法令に従い通知又は公表します。

## 4. 外部サービスと提供先

メール配信には SMTP 事業者、Web Push にはブラウザーの Push サービスを使用します。連携機能や運用では、利用状況に応じて Teams/Power Automate、Discord、Cloudflare Email Workers、Google Gemini、Sentry、Datadog、暗号化バックアップの保存先を利用します。

課題のタイトル・説明はモデレーションのため Google Gemini に送られます。日直関連メールの件名・本文は判定のため Google Gemini に送られる場合があります。Teams・Discord 連携では課題情報等、メール配信では宛先と通知内容、障害監視ではエラーや関連ログが、それぞれ必要な範囲で送られます。受信メール連携では Cloudflare を経由してメール内容を受け取ります。これらのサービスでは国外で情報が取り扱われる場合があります。

委託先には利用目的の達成に必要な範囲で情報を取り扱わせます。法令で認められる場合又は本人の同意がある場合等を除き、個人データを第三者に提供しません。各経路の詳しい取扱いは窓口へお問い合わせください。

## 5. 安全管理と保存

アカウントの認証、アクセス権限の管理、通信の暗号化、障害の監視、バックアップの暗号化等を行います。データベースのバックアップは暗号化して外部の保存先へ転送し、原則14日間、最低3世代を保持します。その他の情報は利用目的に必要な期間又は法令上必要な期間保存し、不要となった情報を適切に削除します。安全管理措置の詳細は、支障のない範囲で窓口から回答します。

## 6. 開示等の請求と苦情

保有個人データの利用目的の通知、開示、訂正・追加・削除、利用停止・消去、第三者提供の停止、第三者提供記録の開示をご希望の方は、第1項の窓口へ、登録メールアドレス、希望する手続、対象情報、希望する回答方法をお知らせください。苦情も同じ窓口で受け付けます。本人確認書類やパスワードなどは、求められる前に送らないでください。

登録済みメールアドレスへの返信等により本人を確認します。必要に応じて、確認に必要な最小限の追加情報をご案内します。代理人の場合は、委任と代理権を確認します。本人確認に用いた情報は、不要となった時点で適切に削除します。

本人が希望する方法で遅滞なく回答します。その方法が困難な場合や、全部又は一部をお受けできない場合は、その旨と理由をお知らせします。開示等の手数料は徴収しません。

## 7. 改訂

本ポリシーを改訂するときは、改訂日と内容を本サービス上で公表します。法令上の通知又は同意が必要な変更には、その手続を行います。
