# 課題通知
- 各種メールはReact Emailで構成します。
- マイクロサービスは`apps/email-compose`ディレクトリに配置してください。
- Node.jsのマイクロサービスを構築し、その中で"メールの構成だけを"担当してください。
- メールの送信ロジックは従来通りのマイクロサービスで行ってください。
- gRPCを使って、Node.jsのマイクロサービスとGoのマイクロサービスが通信できるようにしてください。Webサーバーとしての機能は不要で、gRPCのサーバーとしてのみ動作させてください。
- GoとNode.jsでは実行速度が異なるため、途中にRedisを挟んで管理してください。
- SentryとDatadogの両方を導入し、エラーとパフォーマンス、ログを監視できるようにしてください。
- メールのテンプレートは以下の通りです。
  - ログイン時の認証コード
  - ログイン通知
  - 課題締切通知
  - パスワードリセット
  - ユーザー情報の変更通知
  - トークン・iCal発行通知
  - 不適切投稿の通知(管理者向け)
- メールのテンプレートは、Shadcn/uiのコンポーネントに近づけて設計してください。
- メールのテンプレートは日英対応してください。言語の情報はgRPCのリクエストに含めてください。
