# 投稿の監視

投稿された課題を監視します。

## 不適切投稿の判断基準

以下の基準に基づいて投稿内容を評価し、不適切と判断された場合はDiscordでも通知します。

1.  **ヘイトスピーチ、差別的言動:** 特定の集団や個人に対する攻撃、脅迫、差別を助長する内容（人種、民族、宗教、性別、性的指向、障害などに基づくもの）。
2.  **暴力、脅迫:** 身体的危害を示唆する脅し、テロ行為の奨励、武器の製造・使用方法に関する詳細情報。
3.  **露骨な性的コンテンツ:** ポルノグラフィ、児童の性的虐待に関連する内容、または性的な搾取を助長する内容。
4.  **違法行為の助長:** 薬物乱用、詐欺、サイバー攻撃、著作権侵害などの違法行為を明確に教唆、助長する内容。
5.  **個人情報の流出:** 他人の連絡先、住所、銀行口座情報など、プライベートな機密情報を無断で公開する行為。
6.  **いじめ、ハラスメント:** 特定の個人を執拗に攻撃し、精神的苦痛を与える内容。

## 発見時の処理
- 不適切と判断された投稿はその段階で自動的に非表示にするとともに、別テーブルに保存します。
- 保存はJSON形式で、投稿に関連するメタデータ（投稿者ID、投稿日時、監視日時、判断基準など）も含めます。

## 深刻な不適切投稿に対する対応
- 投稿された内容が脅迫行為にあたると判断した場合、または誰かの身体的安全が脅かされていると感じる場合、DiscordのWebhookに通知するとともに、すべてのadminユーザーに内容を含めてメールで通知します。

## 仕様
### バッチ処理
- 1日に1回実行します。
- 対象は実行時点から過去24時間以内に投稿された課題です。
- 結果はDiscordのWebhookに通知します。

### ファイル構造
```
batches/moderation/
  main.go             # 処理を記述
  moderation          # ビルドされたバイナリ
```
- ビルドされたバイナリは`.gitignore`に含まれています。本番環境へはGitHub ActionsによるCI/CDパイプラインで配信されます。

### その他
- 監視には`gemini-2.5-flash`を利用します。
- バッチ処理はAirFlowで管理されます。
- ユーザーからの通報も受け付けますが、通報時点では通報事実のみを記録し、非同期で判定します。
