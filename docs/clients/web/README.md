# Web クライアント

## 課題一覧の完了フィルター

`/home` の「未完了」「完了済み」はトグルボタンです。Tab で移動し、Enter または Space で選択できます。選択中のボタンをもう一度押すと「すべて」に戻ります。両ボタンの選択状態は `aria-pressed` で伝え、現在の表示条件は画面と読み上げの両方で確認できます。再押下の操作案内は日本語と英語で表示します。

## 課題カードの完了操作

課題カードの左端には、課題名を読み上げ名に含むチェックボックスを常時表示する。チェックありは完了、チェックなしは未完了を表す。Tab で移動し、Space で切り替えられる。フォーカス時にはリングを表示する。

カード内の余白や課題名をクリックしても完了状態を切り替えられる。アクションメニューや編集中の入力・保存・キャンセル操作では切り替えない。編集中は完了チェックボックスも無効にする。

Issue #366 の回帰確認は `apps/web/tests/browser/flows.spec.ts` で行う。未完了・完了の両状態、Tab/Space、フォーカス表示、他のボタンとの独立性を確認する。

## 完了マークの設定

課題の作成・編集フォームで「完了マークを無効にする」を選ぶと、チェックボックスとカードクリックによる完了操作を無効にします。API の `completeTask` も拒否します。無効化を保存すると既存の完了記録を解除します。

管理画面の「課題タイプの初期設定」（`/admin/task-defaults`）でタイプごとの初期値を設定できます（保存は管理者のみ）。設定は新規課題に適用し、既存課題や編集時のタイプ変更には自動適用しません。未設定時は小テストのみ無効、それ以外は有効です。

GraphQL / REST の作成・更新で `is_completion_disabled` を指定できます。作成で省略した場合はタイプの初期値を使い、明示的な `false` も保持します。初期値は `configs` の `task_completion_disabled_<TYPE>` に `true` / `false` として保存します。
